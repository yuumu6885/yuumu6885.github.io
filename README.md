# 日記・備忘録サイト

Markdown ファイルを1つ追加するだけで記事が公開される、日記と備忘録のサイトです。
（Hugo + GitHub Pages。保存すると数分で自動的にサイトに反映されます）

## 記事の書き方（いちばん簡単な方法）

1. 置き場所を選ぶ
   - 日記 → `content/diary/`
   - 備忘録 → `content/memo/`
2. ファイル名を **日付.md** にする（例: `2026-11-26.md`）
   - 同じ日に2つ書くときは `2026-11-26-2.md` や `2026-11-26-ramen.md` のように後ろに何か付ける
   - ファイル名の日付がそのまま記事の日付になります
3. 中身を書く

```markdown
---
title: "今日のタイトル"
tags: [料理, 週末]
---

ここから本文。普通の文章を書けばOK。

## 見出し

- 箇条書き
- **太字**
```

- `title` を省くとタイトルは日付になります。`---` で囲んだ部分ごと省いて本文だけでもOKです。
- `tags` は好きな言葉を `[ ]` の中にカンマ区切りで。タグ一覧ページに自動で載ります。

## スマホから書く（GitHub アプリ／ブラウザ）

1. ブラウザで `github.com/ユーザー名/リポジトリ名` を開く（PC 表示に切り替えると操作しやすいです）
2. `content` → `diary`（または `memo`）を開く
3. 「Add file」→「Create new file」
4. ファイル名に `2026-11-26.md` のように入力し、本文を書く
5. 「Commit changes」を押す → 数分後にサイトへ反映

※ 公式の GitHub アプリはファイル作成ができないことがあるので、ブラウザ版がおすすめです。

## PC から書く

- 同じくブラウザの GitHub で作成するのが手軽です。
- キーボードで `.`（ピリオド）を押すとブラウザ上でエディタ（VS Code）が開き、プレビューしながら書けます。

## 記事を直す・消す

- 直す: ファイルを開いて鉛筆マーク（Edit）→ 修正 → Commit changes
- 下書きにしたい: 先頭に `draft: true` を書くと公開されません
- 消す: ファイルを開いて「…」→「Delete file」

## 画像を載せる

1. `static/images/` に画像をアップロード（Add file → Upload files）
2. 本文に `![説明](/images/ファイル名.jpg)` と書く

## サイト名・説明を変える

`hugo.toml` の `title`（サイト名）、`description`（トップの説明文）、`author` を書き換えてください。

## 構成メモ

| 場所 | 内容 |
|---|---|
| `content/diary/` | 日記の記事 |
| `content/memo/` | 備忘録の記事 |
| `layouts/` | ページのテンプレート |
| `static/css/style.css` | デザイン（色・文字の大きさなど） |
| `.github/workflows/hugo.yml` | 自動公開の設定 |
